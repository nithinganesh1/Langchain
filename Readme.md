# LangChain Learning Notes

Welcome to the LangChain learning directory! This repository contains conceptual notes and practical examples for building AI applications using LangChain.

- [**Introduction to LangChain Ecosystem**](./intro.md)
  - Overview of LangChain, LCEL, LangSmith, and LangServe.

- [**Creating a Basic Chatbot**](./chatbot.md)
  - Notes on setting up environment variables.

  - Chaining basics using LangChain Expression Language (LCEL).

## 🚀 Getting Started

If you are planning to run code based on these notes, ensure you have set up a `.env` file in the root directory with the necessary API keys:

```env
LANGCHAIN_API_KEY="your_langchain_api_key"
LANGCHAIN_PROJECT="your_project_name"
OPENAI_API_KEY="your_openai_api_key"
```

Happy learning! 🤖
